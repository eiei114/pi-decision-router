# Pi SDK 1.5.0 compatibility

This package is verified against the frozen SDK wave: `@earendil-works/pi-agent-core`, `pi-ai`, `pi-coding-agent`, and `pi-tui` are pinned to `1.5.0` for development and tests. Public peer dependency ranges remain unchanged.

The merged [`pi-extension-template` baseline PR #141](https://github.com/eiei114/pi-extension-template/pull/141) verifies this SDK wave and its shared smoke-test pattern. The [upstream Pi 1.5.0 release notes](https://github.com/earendil-works/pi/releases/tag/v1.5.0) change extension tool-argument validation to `@earendil-works/pi-schema`; TypeBox features outside JSON Schema no longer affect tool arguments. This package's `decision_request` schema uses only JSON Schema-compatible object, string, boolean, array, optional-field, and `additionalProperties` constructs. It does not use the unsupported `Type.Refine()`, `Type.BigInt()`, `Type.Undefined()`, codecs, or custom formats. The extension imports `Type` directly from `typebox`, so the pi-ai TypeBox re-export compatibility change does not apply. No deprecated API replacement is required for the APIs this extension uses.

The 1.5.0 release notes do not identify breaking changes to the extension entrypoint, event bus, UI context, compaction, or follow-up message APIs used here; `npm run typecheck` verifies their current type contracts. Public peer dependency ranges remain unchanged.

Run `npm run smoke:pi` to load the package in the actual locally pinned Pi host. `npm run ci` runs the harness. The committed result is `docs/verification/pi-sdk-smoke.json` with `verification_contract=pi-sdk-behavior-v2`. The harness verifies extension registration, the actual routed feature response, handled child-process failure, registration and feature response from a second Pi process plus clean shutdown, and the native host-shell boundary. It checks every installed SDK version against exact pins and uses an isolated temporary Pi agent directory without changing global settings.

The feature path is deterministic and offline, so no paid model inference is made. Pi's host process, extension loader, RPC handling, event adapter, fallback selection, audit write, and feature response are real rather than mocked. The error case launches a deliberately missing child executable and asserts that the router handles and audits the failure. Contract regression tests check both positive and deliberately missing responses. All smoke processes have a 15-second deadline; the shell probe launches the pinned CLI through native Windows PowerShell or `/bin/sh` on POSIX.
